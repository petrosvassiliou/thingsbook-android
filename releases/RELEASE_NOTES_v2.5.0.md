# Thingsbook v2.5.0 (Official Stable · Build 87)

## Highlights

### 1. Tags Power Suite — Search, Sort (`A–Z`, `Most Used`, `Custom`) & Atomic Tag Merge
- **Live Tag Search & Locked Constant-Height Modals:** Search tags instantaneously inside both **Manage Tags** and **Assign Tags** across Android, ChromeOS PWA, and macOS — with constant-height list viewports that never jump or resize as search results change.
- **Smart Tag Sorting:** Sort tags by **A–Z** (default), **Most Used** (with live usage badges across tasks & projects), or **Custom** manual order (`↑` / `↓`).
- **Quick Tag Rename & Merge:** Rename tags or merge duplicate tags (`Merge Into…`) with atomic cross-entity remapping across Tasks, Projects, Areas, and Project Templates — fully synced via Firestore and `.tbbackup`.

### 2. Non-Destructive View & Project Sorting
- Sort tasks on the fly inside Smart Views (`Today`, `Inbox`, `Upcoming`, `Anytime`, `Someday`), `Areas`, and `Projects` by **Manual**, **By Deadline**, **By Duration**, or **Alphabetical (A–Z)** without overwriting manual drag-and-drop `sortOrder`.

### 3. Pin Important Tasks to Top
- Pin priority tasks (`Pin to Top` / `Unpin`) so must-do items stay anchored at the top of `Today`, `Anytime`, and `Project` lists across all platforms, with full backward-compatible `.tbbackup` and Cloud Sync support.

### 4. Duplicate Tasks & Projects (`Ctrl/Cmd+D`) + Batch Multi-Select Upgrades
- **Instant Duplication:** Press `Ctrl+D` / `Cmd+D` (or use the `•••` / right-click / Multi-Select bar) to duplicate an expanded task, all selected tasks in order, or an entire Project (including Headings and Checklists) with localized `(Copy)` naming across all 5 languages.
- **Android Touch Long-Press Multi-Select & Enriched Batch Bar:** Long-press any collapsed task row on Android phones and tablets to immediately enter Multi-Select mode with haptic feedback, backed by an expanded batch bar (**Today**, **Someday**, **Move**, **Tags**, **Pin**, **Duplicate**, **Complete**, **Delete**) across Android, ChromeOS PWA, and macOS.
