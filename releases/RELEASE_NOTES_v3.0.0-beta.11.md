# Thingsbook v3.0.0-beta.11 (Build 102) — Balanced 3+3 Soft Bento Task Modal

> **Pre-Release Notice:** `v3.0.0-beta.11` (Build `102`) is a **3.0 Beta pre-release** for **Android**, **ChromeOS PWA**, and **macOS 14+**. Official Stable `Latest` (`v2.5.0` on `main`) remains untouched for stable-channel users.

## What's New in Beta 11

### Balanced 3+3 Soft Bento Task Modal (Zero Wasted Space, Zero Duplication)
- **3 Logical Property Cards Instead of 6:** Consolidated the 6 narrow right-column property boxes into **3 calm, balanced groups** across **macOS**, **ChromeOS PWA**, and **Android**:
  1. **Schedule (`When · Deadline · Repeat`):** `When`, `This Evening`, `Timeblock`, `Deadline`, and `Repeat` pills together.
  2. **Focus & Dependencies (`Effort · Duration · Waiting On`):** `Effort`, `Duration`, and `Waiting On` pills on one shared row with crisp pill borders.
  3. **Organization (`Project / Area · Categories`):** `Project / Area` (+ `Phase`) alongside `Categories`.
- **Content-Hugging Height & Slim Empty `Attachments` Bar:** Replaced forced `560–620pt` modal stretching with content-hugging `ViewThatFits` sizing on macOS, and collapsed empty `Attachments` into a single slim 1-row drop/attach bar so both columns finish cleanly at the same height.
- **Single-Row De-Duplicated Header & Footer:** Removed the duplicate header folder breadcrumb pill and duplicate footer `Attach Photo or PDF` pill so `Start Focus Timer`, `Duplicate To-Do`, `Delete`, and `✓ Done` fit cleanly on one single row.
