# Thingsbook v3.0.0-beta.4 (Beta Pre-Release · Build 95)

## Highlights — Unified Soft Bento Task Modal Across All Views

### 1. Unified Soft Bento Task Modal (`List | Board | Roadmap | Timeline`)
- **One Consistent, Spacious Task Window Everywhere (`macOS`, `ChromeOS PWA`, `Android`):**
  - Replaced inline list-row card expansion with a crisp, centered **Soft Bento Task Modal** across every view (`Inbox`, `Today`, `Today Timeline`, `Planned`, `Anytime`, `Someday`, `Logbook`, `Areas`, `Perspectives`, `Project List`, `Project Board`, and `Project Roadmap`), eliminating list scroll-jumping and layout reflows while keeping multi-select and cross-container drag-and-drop rock-steady.
  - **Structured Two-Zone Soft Bento Layout:**
    - **Primary Content Zone:** Status checkbox, large Title input (auto-focused on newly created tasks), Voice Dictation, Markdown Notes editor with smart link/map chips, interactive Checklist with ✨ Gemini Magic Breakdown, and File/Photo Attachments.
    - **Properties & Scheduling Bento Grid:** Structured Soft Bento tiles for **When & Reminder** (including Today `This Evening` & **Timeblocking**), **Deadline**, **Duration & Effort** (`Quick Win ⚡`, `Medium`, `Deep Focus 🧠`), **Waiting On (Dependencies)**, **Categories**, **Project / Area / Phase**, and **Repeat**, plus **Focus Timer**, **Pin**, **Duplicate**, and **Delete** actions.

### 2. Fast Desktop & Touch Ergonomics
- **Desktop & Chromebook (`macOS` & `ChromeOS PWA`):** Single-click selects rows/cards (`Cmd/Ctrl+click` & `Shift+click` multi-select), while **double-click**, **`Return` / `Enter`**, **`Space`**, the subtle hover **Open** icon, or **`+ New To-Do` (`Cmd/Ctrl+N`)** opens the Soft Bento Task Modal (`Esc`, `Cmd/Ctrl+Return`, `Done`, or clicking outside commits drafts and closes).
- **Android Touch (`Phone & Tablet`):** Single-tap on any task row/card/bar (when not in multi-select mode) or **`+` FAB** opens the Soft Bento Task Modal; long-press initiates multi-select and drag-and-drop.
