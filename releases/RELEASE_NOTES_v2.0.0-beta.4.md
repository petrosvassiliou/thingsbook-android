# Thingsbook `v2.0.0-beta.4` Beta (Build `48`) — Android, ChromeOS & macOS

> **Beta Pre-Release Channel (`2.0` Preview)** — Official stable **`v1.8.1`** remains the default `latest` release on `main` and production Hosting (`https://thingsbook-prod.web.app`). Existing `v1.7.x`, `v1.8.x`, and `v2.0.0-beta.x` installations can upgrade seamlessly in-place to `v2.0.0-beta.4` (Build `48`).

---

## ✨ What's Improved in `v2.0.0-beta.4`

### Unified Sidebar & Menu Option Formatting for Weekly Review & Templates
- **Consistent Unselected Menu Typography & Background**: Removed the bold/semi-bold blue text and permanent blue pill highlight on **Weekly Review** (and **Project Templates**) across the sidebar and navigation strip so they share the exact same clean font weight, text color, icon sizing, spacing, and hover/selection formatting as all other Smart View menu options (`Inbox`, `Today`, `Upcoming`, `Anytime`, `Someday`, `Logbook`, `Trash`).
- **Subtle Right-Aligned Count Styling**: Aligned the optional Weekly Review count in the sidebar with the standard muted right-aligned count typography used by all other Smart View rows across Android, ChromeOS, and macOS.

---

## 📦 Installation & Isolated Beta Links

- **Android (`APK`, Build `48`)**: Download `Thingsbook-v2.0.0-beta.4-GTD-Full.apk` below to install or upgrade over `v1.8.x` / `v2.0.0-beta.x` in place without losing local tasks or Cloud Sync sessions.
- **ChromeOS / Web (`Isolated Beta Channel`)**: Live at `https://thingsbook-prod--beta-63kq14fo.web.app` (production `https://thingsbook-prod.web.app` remains untouched on `v1.8.1`).
- **macOS (`Universal Apple Silicon + Intel DMG`, macOS 14+)**: Download `Thingsbook-macOS-v2.0.0-beta.4-Universal.dmg` below, or install in one command:
  ```bash
  THINGSBOOK_VERSION=v2.0.0-beta.4 bash <(curl -fsSL https://raw.githubusercontent.com/petrosvassiliou/thingsbook-android/beta-2.0/macos/install.sh)
  ```
