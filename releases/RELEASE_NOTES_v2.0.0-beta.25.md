## Thingsbook v2.0.0-beta.25 (Build 69) — Pre-Release

### UX & Task Card Polish Across Android, ChromeOS PWA & macOS
- **No Automatic Text Selection When Opening Tasks**: Opening an existing task (with or without notes) no longer auto-focuses or highlights the task title or notes text in blue across Android, ChromeOS PWA, and macOS. Notes open in a clean, calm preview state, and only brand-new untitled tasks auto-focus the empty title field.
- **1-Click "This Evening" + Immediate Close in Today View**: Exclusively inside the **Today** Smart View, expanding any open daytime task now displays a dedicated `🌙 This Evening` (*Heute Abend* / *Ce soir* / *Stasera* / *Esta noche*) pill right beside the *When* badge. Clicking it saves any pending edits, moves the task to *This Evening*, and immediately collapses the card in a single click.
