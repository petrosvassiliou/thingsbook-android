# Thingsbook v3.0.0-beta.8 (Build 99) — Clear Sidebar Distinction Between Perspectives & Areas

> **Pre-Release Notice:** `v3.0.0-beta.8` (Build `99`) is a **3.0 Beta pre-release** for **Android**, **ChromeOS PWA**, and **macOS 14+**. Official Stable `Latest` (`v2.5.0` on `main`) remains untouched for stable-channel users.

## What's New in Beta 8

### 1. Self-Contained Soft Bento `Perspectives` (`Perspektiven`) Card
- **Perspectives** (`Perspektiven` / `Perspectives` / `Prospettive` / `Perspectivas`) are dynamic saved filter views, not workspace folders. They are now enclosed inside their own dedicated **Soft Bento Card** matching the `Someday` & `Review` mini-cards right above them, accented with a distinct filter/mosaic icon and uppercase section label.
- Even when zero custom perspectives have been saved yet, the `Perspectives` card closes cleanly with its own Soft Bento border **plus** an unconditional structural divider below it, so Areas below never visually appear nested inside `Perspectives`.

### 2. Explicit `Areas` (`Bereiche`) & Standalone `Projects` (`Projekte`) Section Headers
- Added a dedicated **`AREAS` (`BEREICHE`)** section header row (Folder icon + uppercase localized title + `N/8` capacity counter + quick `+` / Manage Areas action) right above the Area list across **Android**, **ChromeOS PWA**, and **macOS**.
- Added an explicit **`PROJECTS` (`PROJEKTE`)** section header above unassigned standalone projects whenever any exist, and added a clean vertical separator between Perspectives pills and Area pills in the compact Android phone navigation strip.
