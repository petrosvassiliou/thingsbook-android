# Thingsbook v3.0.0-beta.5 (Beta Pre-Release · Build 96)

## Highlights — Quick Row Editing, Calm Single-Row Top Bar, Full-Width View/Project Titles, Modal Footer Pinning & Full-Screen Timelines

### 1. Inline Task Row Quick Edit + Spacious Modal Hybrid
- **Quick Edits Directly on Every Task Row (`Android`, `ChromeOS PWA`, `macOS`):**
  - Added **Inline Title Quick-Rename** (`✏️` / `F2`) directly inside collapsed task rows so you can rename tasks in place (`Enter` or blur saves, `Esc` cancels) without opening the modal.
  - Wired **1-Click Interactive Property Badges & Quick Actions** right on collapsed task rows (`When`, `Deadline`, `Timeblock`, `Duration`, `Effort`, `Repeat`, `Reminder`, `Waiting On`, and `Categories`) so everyday scheduling and metadata tweaks open their lightweight picker immediately, while tapping the row body or `Open Details` launches the full Two-Zone Soft Bento Task Modal.

### 2. Sticky Non-Clipped Task Modal Footer
- Bounded the Unified Soft Bento Task Modal strictly within live window bounds and pinned the top Header and bottom Footer (`Focus Timer`, `More Options`, `Done` / `Fertig`) with an independent scrollable middle body so the bottom action buttons are **never cut off** at any window height.

### 3. Clean, Decluttered Top Bar
- Removed redundant top-bar icons already accessible in the Sidebar / Hamburger Menu (`☰`) and Settings (`⚙️`) — keeping a calm, single-row top bar (`Sidebar Toggle`, `Quick Find`, `Voice Capture`, `Gemini`, `Cloud Sync`, and `Settings`) that never wraps into a cluttered second icon row on narrow windows.

### 4. Unbroken Smart View & Project Titles
- Fixed mid-word wrapping on Smart View headers (e.g., `Heute`) and Project headers (e.g., `Informationsverbund 2.0`) by giving titles dedicated full-width space, consolidating secondary project icon actions into a tidy Project Actions menu, and allowing clean 2-line word-boundary titles in the Sidebar with full tooltips.

### 5. Full-Screen Timeline Mode (`Today Timeline` & `Project Roadmap`)
- Added a 1-click **Full Screen (`Vollbild`)** toggle (plus `Esc` / Back exit) to both **Today Daily Timeline (`Zeitplan`)** and **Project Roadmap Timeline** across Android, ChromeOS PWA, and macOS so schedules and Gantt timelines can expand edge-to-edge across the entire window.
