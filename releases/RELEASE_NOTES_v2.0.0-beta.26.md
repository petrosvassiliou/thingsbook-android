# Thingsbook v2.0.0-beta.26 (Build 70) — Pre-Release Notes

## macOS — Compact, Quiet Calendar Appointments (Android & ChromeOS Parity)
- **Single Subtle Grouped Container**: Replaced per-appointment blue cards with a single compact, low-contrast grouped surface (`subtleContainer` + hairline border) in **Today**, **Upcoming**, and **Today Timeline**, keeping visual focus squarely on tasks.
- **Smaller, Subordinate Typography & Tighter Spacing**: Reduced calendar appointment titles (`12pt` regular), times (`11pt` medium secondary monospaced digits), and all-day pills (`10pt` tinted badge) with tight `3pt` row padding and a `3×13pt` calendar color bar—matching Android and ChromeOS PWA.
- **Cleaner Trailing Metadata**: Replaced the inline *"Open in Calendar"* capsule button on every row with the quiet muted calendar name (`10.5pt` tertiary) plus hover highlight and tooltip; clicking an appointment still opens it directly in Apple Calendar.
