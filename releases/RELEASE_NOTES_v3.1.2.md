# Thingsbook v3.1.2 (Build 115) — Calm 24-Hour Project Attention Rule & Clean Header Polish

**Thingsbook `v3.1.2` (Build `115`)** refines **Project Header ergonomics** and introduces a **24-Hour Grace Rule** for *"Requires attention"* across **Android & Googlebook OS**, **ChromeOS / Web PWA**, and **macOS**.

---

## ✨ What’s New in `v3.1.2`

### 1. Calm 24-Hour Grace Window for *"Requires Attention"* (`Aufmerksamkeit nötig`)
- **Zero False Alarms on New Projects (`0/0`):** Newly created projects stay completely free of the *"Requires attention"* warning for the first **24 hours**, giving you time to set up phases and tasks without visual noise.
- **Zero False Alarms on Newly Completed Projects (`3/3`):** Checking off the final open task in a project keeps the header clean for **24 hours** (showing the emerald **`✓ Complete`** button on the right), and gently displays *"Requires attention"* after a day if the project is still sitting open with no next actions.

### 2. Clean Separation of Status Pill & `✓ Complete` Button
- **Left Progress Pill = Pure Visual Status:** The leading progress capsule/ring next to the project title is strictly a visual status indicator again (preventing duplicate controls or accidental clicks near the title), while **`✓ Complete` (`✓ Abschließen`)** lives clearly on the top-right next to `✏️` Edit and `⋯` More.
