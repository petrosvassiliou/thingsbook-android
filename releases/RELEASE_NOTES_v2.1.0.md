# Thingsbook v2.1.0 (Build 73) — Unified Inline Task Editor Across All Platforms

**Thingsbook `v2.1.0` (Build `73`)** refines and unifies the inline task editor across **Android, ChromeOS PWA, and macOS**, eliminating duplicate icon rows while keeping all GTD scheduling, AI breakdown, attachment, voice, and focus tools right at your fingertips.

---

## ✨ What’s New in v2.1.0

- **🎯 Unified Single-Row Inline Task Footer (Android, ChromeOS & macOS)**:
  - Removed all **6 duplicate bottom action icons** (`When`, `Timeblock`, `Repeat`, `Project/Area`, `Tags`, `Deadline`) that duplicated the labeled metadata pills right above them.
  - Kept the expressive, labeled metadata pills (`📅 When`, `⏱️ Timeblock`, `🔁 Repeat`, `🏳️ Deadline`, `📁 Project / Area`, `+ Tags`) on the left side of a **single unified footer row**, paired cleanly on the right with **Focus Timer (`⏲️`)**, a crisp **`⋯` More Actions** menu, and **Done (`✓`)**.
- **✨ Contextual Magic Subtasks Inside the Checklist Bar**:
  - Moved **Magic Breakdown (`✨ Magische Teilaufgaben`)** directly into the trailing end of the *Add checklist item…* input bar where subtasks are generated.
- **📎 Clean Overflow Menu & Zero Empty Attachment Clutter**:
  - Tasks without attachments no longer display an extra standalone attachment button row; **Attach Photo / PDF (`📎`)**, **Take Photo (`📷`)**, **Voice Input (`🎤`)**, **Duplicate To-Do (`📋`)**, and **Delete (`🗑️`)** live neatly inside the **`⋯`** menu (while thumbnail strips still appear automatically as soon as files are attached).
