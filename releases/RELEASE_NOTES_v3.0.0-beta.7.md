# Thingsbook v3.0.0-beta.7 (Beta Pre-Release · Build 98)

## Highlights — Balanced Left-Aligned Workspace Canvas & Collision-Free 2-Row Sidebar Footer Across ChromeOS PWA, macOS & Android

### 1. Natural Left-Aligned Workspace Spacing Next to the Sidebar (`ChromeOS PWA`, `macOS`, `Android`)
- **Removed Over-Centered Canvas Gap:** Anchored the main workspace column cleanly to the leading edge right beside the Sidebar (`24px`/`26pt` uniform gutter matching the top Quick Find bar, up to `960px` comfortable reading width) on **ChromeOS PWA** and **macOS** (and tightened Android's sidebar-to-content gutter to match), eliminating the huge blank gap that previously pushed `Today / Heute` and task lists into the middle of wide screens.
- **Calm Left-Aligned Empty State Cards:** Replaced floating centered empty-state text with a subtle, leading-aligned Soft Bento empty-state card directly underneath the view header across all 3 platforms.

### 2. Collision-Free 2-Row Sidebar Footer (`+ New Project ▾` + Utility Dock)
- Restructured the Sidebar bottom footer across **ChromeOS PWA**, **macOS**, and **Android** into two clean rows:
  1. **Row 1:** Full-width Soft Bento **`+ New Project ▾` (`+ Neues Projekt ▾`)** button with `+ New Project` on the left and the dropdown chevron on the right—100% untruncated in all 5 languages (`EN`, `DE`, `FR`, `IT`, `ES`) and never overlapping neighboring icons.
  2. **Row 2:** Evenly spaced **Utility Dock** (`Logbook`, `Trash`, `Areas X/8`, and `Categories`) with comfortable click/tap spacing.
