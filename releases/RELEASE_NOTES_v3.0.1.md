# Thingsbook v3.0.1 (Build 112) — Streamlined Context Menus Across Android, ChromeOS & macOS

**Thingsbook `v3.0.1` (Build `112`)** refines the right-click and long-press **Task Context Menu** across **Android & Googlebook OS**, **ChromeOS / Web PWA**, and **macOS** so everyday actions fit cleanly on screen with **zero scrolling** and **`Delete` is always immediately visible**.

---

## ✨ What’s New in `v3.0.1`

### Streamlined High-Signal Task Context Menu (List & Kanban Board Views)
- **Focused ~10-Item Menu:** Concentrates strictly on high-frequency actions:
  1. **Open Details** *(opens the Two-Column Soft Bento Task Modal)*
  2. **Complete / Reopen**
  3. **When…**
  4. **Deadline…**
  5. **Move…** *(Project / Area / Phase)*
  6. **Categories…**
  7. **Pin to Top / Unpin**
  8. **Mark / Remove Milestone (`◆`)**
  9. **Select** *(touch multi-select on Android/Googlebook)* & **Duplicate**
  10. **Mark as Canceled** & **Delete** *(always visible at the bottom without scrolling)*
- **Cleaner Separation of Concerns:** Secondary planning controls (*Timeblock*, *Duration presets `15m`–`8h`*, *Effort `Low/Medium/High`*, *Waiting On dependencies*, *Repeat*, *Focus Timer*, *Copy Task*, and *Gemini Magic Breakdown*) now live cleanly inside the **Two-Column Soft Bento Task Modal** and **Wide-Screen Right-Side Inspector**, eliminating vertical menu bloat.

## 📥 Download & Upgrade (`v3.0.1`, Build `112`)

- **📱 Android & Googlebook OS (`versionCode 112`, Universal Signed APK)**:
  - Download **`Thingsbook-v3.0.1-GTD-Full.apk`** below or use **Settings → App Update → Check for Updates** inside the app.
- **💻 ChromeOS & Web (Standalone Offline PWA)**:
  - Live at **[https://thingsbook-prod.web.app](https://thingsbook-prod.web.app)** — updates automatically in place.
- **🍎 macOS (`Build 112`, Universal Apple Silicon `arm64` + Intel `x86_64`, macOS 14+)**:
  - Upgrade via **Settings → Updates → Install & Relaunch**, download **`Thingsbook-macOS-v3.0.1-Universal.dmg`** below, or run:
    ```bash
    curl -fsSL https://raw.githubusercontent.com/petrosvassiliou/thingsbook-android/main/macos/install.sh | bash
    ```
